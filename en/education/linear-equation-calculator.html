What the linear equation calculator does

The calculator solves linear equations in one variable and works in four modes: equation (typed as it is written on paper: with brackets, fractions and the variable on both sides), an equation from coefficients ax + b = cx + d, linear inequalities with a number line and proportions A : B = C : D. Every example comes with a step-by-step solution, a check by substitution and, for equations, a graph of two lines where the solution is their intersection point.

How to solve a linear equation

A linear equation has the form ax + b = 0 or, more generally, ax + b = cx + d. To solve it, expand the brackets, move the terms with the variable to one side and the numbers to the other (a term changes its sign when it crosses the equals sign), combine like terms and divide both sides by the coefficient of x.

Example: 3x − 7 = 2x + 5. Moving the terms gives 3x − 2x = 5 + 7, so x = 12. Check: 3·12 − 7 = 29 and 2·12 + 5 = 29. With brackets: 2(x + 3) = 14, that is 2x + 6 = 14, 2x = 8, x = 4. If the equation has fractions, as in (x + 1)/2 = x/3 + 4, multiply both sides by the least common multiple of the denominators, here 6: 3(x + 1) = 2x + 24, 3x + 3 = 2x + 24, so x = 21.

Infinitely many solutions and no solution

If the coefficient of x becomes zero after moving the terms, the variable disappears. The equation 2x + 1 = 2x + 5 leads to 1 = 5, which is impossible, so there are no solutions: on the graph the lines are parallel. The equation 2(x + 1) = 2x + 2 leads to 0 = 0, which is true for every x, so there are infinitely many solutions: the lines coincide.

Linear inequalities

Inequalities are solved like equations, with one rule: when both sides are divided by a negative number, the inequality sign flips. For example, −2x + 3 > 7 gives −2x > 4, and after dividing by −2 we get x < −2, that is the interval (−∞; −2). For the non-strict signs ≤ and ≥ the boundary is part of the answer and is shown as a filled dot on the number line.

Proportions

The proportion A : B = C : D holds when the product of the extremes equals the product of the means: A·D = B·C. The unknown term is found by division. For 3 : 4 = 9 : x we get 3·x = 4·9, so x = 36 / 3 = 12.

All calculations are exact: the coefficients are kept as rational numbers, so 1/3 is never turned into 0.333 during the solution.

FAQ

What is a linear equation?

A first-degree equation in one variable that reduces to the form ax + b = 0 where a and b are numbers. For example, 3x − 7 = 2x + 5 is a linear equation.

How do I find x in ax + b = 0?

Move b to the right: ax = −b, then divide both sides by a: x = −b/a. For 2x − 8 = 0 we get x = 8/2 = 4.

How do I solve an equation with brackets?

Expand the brackets first, then combine like terms. For 2(x + 3) = 14 we get 2x + 6 = 14, 2x = 8, x = 4.

How do I solve an equation with fractions?

Multiply both sides by the least common multiple of the denominators. For (x + 1)/2 = x/3 + 4 it is 6: 3(x + 1) = 2x + 24, so x = 21. The calculator shows this step and works with fractions exactly.

When does a linear equation have no solution?

When the variable disappears after simplifying and the equality is false. For example, 2x + 1 = 2x + 5 gives 1 = 5, so there is no solution.

When are there infinitely many solutions?

When the variable disappears and the equality is true for every x. For example, 2(x + 1) = 2x + 2 gives 0 = 0: any number is a solution.

Can I enter fractions and decimals?

Yes: 1/2, 0.5, −3/4. The calculator works exactly with rational numbers, so the answer comes out as a fraction and the decimal value is added separately.

Can I use a variable other than x?

Yes, one variable letter is allowed, for example y or t. If the equation contains two different letters, the calculator will tell you.

What if the equation contains x²?

If x² does not cancel (as in x² + x = x² + 3), it is a quadratic equation. The calculator will point you to the quadratic equation calculator.

Why does the inequality sign flip when dividing by a negative number?

Because multiplying or dividing by a negative number reverses the order of numbers on the number line: from 2 < 3, multiplying by −1 gives −2 > −3. So −2x > 4 gives x < −2.

What is a proportion and its basic property?

A proportion is an equality of two ratios, A : B = C : D. The basic property: the product of the extremes equals the product of the means, A·D = B·C.

How do I check the answer?

Substitute the x you found into both sides of the original equation: if the numbers match, the answer is right. The calculator does this check automatically and shows the substitution.
