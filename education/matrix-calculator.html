Що вміє калькулятор матриць

Калькулятор виконує всі основні дії з матрицями до 6×6: додавання, віднімання, множення, множення на число, піднесення до степеня (також від'ємного) і транспонування. Він знаходить визначник трьома способами, обернену матрицю, ранг, слід і розв'язує матричне рівняння AX = B. Елементи вводяться цілими, десятковими чи дробами, а відповіді записуються точно, наприклад −7/120. Кожна дія супроводжується покроковим розв'язанням.

Додавання й множення матриць

Додавати й віднімати можна матриці однакового розміру: cᵢⱼ = aᵢⱼ ± bᵢⱼ. Добуток A × B існує, коли стовпців у A стільки ж, скільки рядків у B: cᵢⱼ = aᵢ₁b₁ⱼ + aᵢ₂b₂ⱼ + … Множення матриць не комутативне: A × B, як правило, не дорівнює B × A. Для A = [[1,2],[3,4]] і B = [[0,1],[1,0]] маємо A × B = [[2,1],[4,3]]. Степінь Aⁿ — n-кратний добуток: для [[1,1],[1,0]]¹⁰ виходить [[89,55],[55,34]] (числа Фібоначчі).

Визначник матриці

Визначник є лише в квадратних матриць. Для 2×2: det = ad − bc, наприклад для [[1,2],[3,4]] це 1·4 − 2·3 = −2. Для 3×3 є правило Саррюса (три добутки з плюсом і три з мінусом) та розклад за рядком: det = Σ aᵢⱼ·(−1)^(i+j)·Mᵢⱼ. Для більших матриць зручний метод Гаусса: зводимо до трикутного вигляду, і det дорівнює добутку діагоналі (зі знаком від обмінів рядків). Для [[2,1,3],[0,−1,4],[1,2,1]] визначник −11.

Обернена матриця

Обернена матриця A⁻¹ задовольняє A·A⁻¹ = E й існує лише при det A ≠ 0. Калькулятор знаходить її методом Гаусса–Жордана: записує [A | E] і зводить ліву частину до одиничної, права стає оберненою. Другий спосіб — формула A⁻¹ = adj A / det A через алгебраїчні доповнення. Для [[1,2],[3,4]] обернена [[−2, 1], [3/2, −1/2]]. Якщо det = 0, матриця вироджена, і калькулятор покаже, у якому стовпці немає ведучого елемента.

Ранг матриці

Ранг — максимальна кількість лінійно незалежних рядків (чи стовпців); його знаходять, зводячи матрицю до ступінчастого вигляду й рахуючи ненульові рядки. Для [[1,2,3],[4,5,6],[7,8,9]] ранг 2, бо третій рядок дорівнює 2·(другий) − (перший), а визначник нуль. Ранг квадратної n×n матриці дорівнює n тоді й лише тоді, коли вона невироджена.

Розв'язання AX = B

Для невиродженої квадратної A розв'язок єдиний: X = A⁻¹B. Калькулятор виконує [A | B] → [E | X] методом Гаусса–Жордана та перевіряє A·X = B. Для [[2,1],[1,3]]·X = [[5],[10]] виходить x = 1, y = 3. Якщо A вироджена чи неквадратна, застосовується теорема Руше–Капеллі: розв'язків немає, якщо rank A < rank [A | B]; безліч, якщо ранги рівні, але менші за кількість невідомих, тоді виводиться загальний розв'язок з вільними змінними.

Де застосовують матриці

Матриці описують системи лінійних рівнянь, перетворення в комп'ютерній графіці (обертання, масштаб, зсув), ланцюги Маркова, моделі «витрати–випуск» в економіці, нейронні мережі, а також зображення й таблиці даних. Поняття визначника й оберненої матриці лежать в основі лінійної алгебри.

Усі елементи обробляються як точні раціональні числа: 1/3 залишається дробом, а не 0,333. Для великих матриць показуються ключові стани, а не кожне перетворення окремо.

Часті запитання

Як перемножити дві матриці?

Кожен елемент добутку cᵢⱼ — сума добутків елементів i-го рядка першої матриці на j-й стовпець другої. Кількість стовпців першої має дорівнювати кількості рядків другої.

Чому A × B не дорівнює B × A?

Множення матриць не комутативне: порядок множників змінює результат, а іноді один із добутків навіть не існує через розміри.

Як знайти визначник матриці 3×3?

За правилом Саррюса, розкладом за рядком чи методом Гаусса. Для [[2,1,3],[0,−1,4],[1,2,1]] визначник −11.

Як знайти обернену матрицю?

Методом Гаусса–Жордана: [A | E] → [E | A⁻¹], або за формулою A⁻¹ = adj A / det A. Для [[1,2],[3,4]] це [[−2, 1], [3/2, −1/2]].

Коли обернена матриця не існує?

Коли визначник дорівнює нулю (матриця вироджена) або матриця не квадратна. Тоді ранг менший за розмір.

Що таке ранг матриці?

Максимальна кількість лінійно незалежних рядків (стовпців). Його знаходять зведенням до ступінчастого вигляду: це кількість ненульових рядків.

Як розв'язати матричне рівняння AX = B?

Якщо A невироджена, X = A⁻¹B; калькулятор виконує [A | B] → [E | X]. Для вироджених A аналізується сумісність за Руше–Капеллі.

Що таке транспонована матриця?

Матриця Aᵀ, у якої рядки й стовпці міняються місцями: елемент (i, j) стає елементом (j, i).

Чи можна вводити дроби й десяткові числа?

Так: 2, -1,5, 3/4. Числа обробляються точно, тому 1/3 лишається дробом, а не 0,333.

Як піднести матрицю до степеня?

Помножити матрицю саму на себе n разів. Для від'ємного n спершу береться обернена. Для [[1,1],[1,0]]¹⁰ виходить [[89,55],[55,34]].

Що таке слід матриці?

Сума елементів головної діагоналі квадратної матриці. Він показується на вкладці «Ранг».

Скільки матриці до 6×6 це багато?

Для навчальних задач цього достатньо. Для великих матриць проміжні кроки показуються скорочено: по одному стану на кожен ведучий стовпець.
