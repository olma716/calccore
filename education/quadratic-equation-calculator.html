Що вміє калькулятор квадратного рівняння

Калькулятор розв'язує квадратне рівняння ax² + bx + c = 0 і працює в п'яти режимах: розв'язання (корені через дискримінант або виділення повного квадрата), вершина й графік параболи, розкладання на множники, побудова рівняння за коренями і розв'язання квадратних нерівностей. Коефіцієнти можна вводити цілими, десятковими або дробами. Корені показуються точно: дробами, радикалами (наприклад (-1 + √5)/2) або комплексними числами, а також десятковим наближенням.

Як розв'язати квадратне рівняння через дискримінант

Спершу обчислюють дискримінант D = b² - 4ac. Якщо D > 0, рівняння має два дійсні корені x = (-b ± √D)/(2a). Якщо D = 0, корінь один: x = -b/(2a). Якщо D < 0, дійсних коренів немає, а комплексні корені дорівнюють (-b ± i√|D|)/(2a).

Приклад: 2x² - 3x - 5 = 0 дає D = 9 + 40 = 49, √D = 7, тому x₁ = (3 + 7)/4 = 2,5, x₂ = (3 - 7)/4 = -1. Для x² + x - 1 = 0 дискримінант 5 не є повним квадратом, тому корені залишаються в радикалах: x = (-1 ± √5)/2 ≈ 0,618034 і -1,618034. Для x² + 2x + 5 = 0 дискримінант -16, комплексні корені -1 ± 2i. Для x² - 6x + 9 = 0 дискримінант 0, корінь x = 3.

Вершина, графік і розкладання на множники

Вершина параболи має координати x₀ = -b/(2a), y₀ = c - b²/(4a), а вісь симетрії задається x = x₀. Для x² - 4x + 3 вершина (2; -1), корені 1 і 3. При a > 0 вітки йдуть вгору, при a < 0 вниз.

Якщо корені x₁ і x₂ відомі, тричлен розкладається на множники: ax² + bx + c = a(x - x₁)(x - x₂). Наприклад, x² - 5x + 6 = (x - 2)(x - 3). За теоремою Вієта x₁ + x₂ = -b/a і x₁·x₂ = c/a, тому рівняння з коренями 2 і -3 має вигляд x² + x - 6 = 0.

Квадратні нерівності

Щоб розв'язати нерівність ax² + bx + c > 0, знаходять корені й дивляться на знак a: поза коренями тричлен має знак a, між коренями протилежний. Для x² - 5x + 6 > 0 корені 2 і 3, a > 0, тому розв'язок (-∞; 2) ∪ (3; +∞), а для x² - 5x + 6 < 0 розв'язок (2; 3).

Усі обчислення точні: коефіцієнти зберігаються як раціональні числа, корені записуються дробами й радикалами.

Часті запитання

Що таке квадратне рівняння?

Рівняння виду ax² + bx + c = 0, де a ≠ 0. Числа a, b, c називають коефіцієнтами, c вільним членом.

Як знайти дискримінант?

D = b² - 4ac. Для 2x² - 3x - 5 = 0 це (-3)² - 4·2·(-5) = 9 + 40 = 49.

Скільки коренів має квадратне рівняння?

Два різні дійсні при D > 0, один (подвійний) при D = 0 і жодного дійсного при D < 0. У комплексних числах корені є завжди.

Як розв'язати неповне квадратне рівняння?

Якщо c = 0, виносять x за дужки: x(ax + b) = 0, звідси x = 0 або x = -b/a. Якщо b = 0, то x² = -c/a, і корені ±√(-c/a), якщо -c/a ≥ 0.

Що робити, якщо дискримінант від'ємний?

Дійсних коренів немає. Калькулятор показує комплексні корені (-b ± i√|D|)/(2a), де i² = -1.

Як виділити повний квадрат?

Поділити на a, перенести c/a вправо й додати до обох частин (b/(2a))², щоб ліва частина стала (x + b/(2a))². Потім взяти квадратний корінь. Режим «Виділення повного квадрата» показує ці кроки.

Як знайти вершину параболи?

x₀ = -b/(2a), y₀ = c - b²/(4a). Для x² - 4x + 3 вершина (2; -1).

Що таке теорема Вієта?

Для коренів x₁, x₂ рівняння ax² + bx + c = 0 виконується x₁ + x₂ = -b/a і x₁·x₂ = c/a. Це зручно для перевірки й підбору цілих коренів.

Як розкласти квадратний тричлен на множники?

Знайти корені й записати a(x - x₁)(x - x₂). Для x² - 5x + 6 корені 2 і 3, тому (x - 2)(x - 3). Якщо D < 0, над дійсними числами тричлен не розкладається.

Як скласти квадратне рівняння за коренями?

Для коренів x₁, x₂ і коефіцієнта a: a(x² - (x₁ + x₂)x + x₁x₂) = 0. Для коренів 2 і -3 маємо x² + x - 6 = 0.

Як розв'язати квадратну нерівність?

Знайти корені відповідного рівняння, врахувати знак a й вибрати інтервали, де тричлен має потрібний знак. Для x² - 5x + 6 > 0 відповідь (-∞; 2) ∪ (3; +∞).

Чи можна вводити дроби й десяткові коефіцієнти?

Так: 0,5, -2,5, 3/4. Калькулятор рахує точно на раціональних числах, тому корені виходять дробами й радикалами, а не округленими десятковими.
