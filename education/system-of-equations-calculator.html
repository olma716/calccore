Що вміє калькулятор системи рівнянь

Калькулятор розв'язує системи лінійних рівнянь із двома або трьома невідомими. Для системи 2×2 можна обрати метод підстановки, додавання (елімінації) або Крамера, для 3×3 — метод Гауса чи Крамера. Рівняння вводяться так, як записані на папері (з дужками, дробами й змінними по обидва боки від знака «=») або коефіцієнтами. Для кожної системи показано розв'язання по кроках, перевірку підстановкою, а для 2×2 ще й графік двох прямих, де розв'язок є точкою їх перетину.

Метод підстановки

Спочатку одну змінну виражають з одного рівняння, потім підставляють в інше й отримують рівняння з однією змінною. Знайшовши її, повертаються до виразу й обчислюють другу змінну. Для системи x + y = 5, 2x − y = 1 маємо y = 5 − x, тоді 2x − (5 − x) = 1, 3x − 5 = 1, x = 2 і y = 5 − 2 = 3.

Метод додавання (елімінації)

Рівняння множать на такі числа, щоб коефіцієнти при одній із змінних стали однаковими за модулем, а потім додають або віднімають рівняння, щоб ця змінна зникла. Для тієї самої системи коефіцієнти при y вже протилежні (+1 і −1): додаємо рівняння, отримуємо 3x = 6, x = 2, а з першого рівняння y = 5 − 2 = 3.

Метод Крамера (визначники)

Для системи ax + by = c, dx + ey = f визначники такі: D = ae − bd, Dx = ce − bf, Dy = af − cd, а розв'язок x = Dx / D, y = Dy / D (якщо D ≠ 0). Для x + y = 5, 2x − y = 1 маємо D = -3, Dx = -6, Dy = -9, тому x = 2 і y = 3. Для систем 3×3 визначники рахують за правилом Саррюса: D = 7, Dx = 7, Dy = 14, Dz = 21 для системи x + y + z = 6, 2x − y + z = 3, x + 2y − z = 2, звідки x = 1, y = 2, z = 3.

Метод Гауса

Систему записують розширеною матрицею й рядковими перетвореннями (обмін рядків, ділення рядка на число, віднімання рядка, помноженого на число) зводять до вигляду, з якого розв'язок видно одразу. Калькулятор показує матрицю після кожного кроку. Метод працює й тоді, коли визначник дорівнює нулю, і дає ранг матриці.

Безліч розв'язків і випадок без розв'язків

Якщо в системи рівняння залежні, наприклад x + y = 2 і 2x + 2y = 4, то розв'язків безліч: прямі збігаються, а калькулятор запише загальний розв'язок (наприклад, x = 2 − y, де y — будь-яке число). Якщо рівняння суперечливі, як x + y = 2 і x + y = 5, розв'язків немає: прямі паралельні, а при зведенні з'являється рядок 0 = c з c ≠ 0.

Усі обчислення точні: коефіцієнти зберігаються як раціональні числа, тому розв'язок виходить дробом без округлень.

Часті запитання

Що таке система лінійних рівнянь?

Набір кількох лінійних рівнянь із тими самими невідомими, які треба розв'язати одночасно: знайти значення змінних, що задовольняють усі рівняння.

Який метод обрати для системи 2×2?

Підстановка зручна, коли в якомусь рівнянні коефіцієнт при змінній дорівнює 1. Додавання швидше, коли коефіцієнти легко зрівняти. Крамер зручний для формульного розв'язання й коли треба знати визначник.

Коли метод Крамера не працює?

Коли головний визначник D = 0: розв'язку або немає, або безліч. Калькулятор тоді визначає, який із випадків, зведенням матриці методом Гауса.

Скільки розв'язків може мати система?

Один (прямі перетинаються), жодного (прямі паралельні) або безліч (прямі збігаються). Для 3×3 це відповідні взаємні положення трьох площин.

Як записати систему, якщо змінні в обох частинах?

Просто введіть рівняння як є, наприклад 2x + 3 = y - 1 і x - y = 4. Калькулятор перенесе змінні ліворуч, а числа праворуч і покаже цей крок.

Чи можна використовувати дроби й десяткові числа?

Так: 1/2, 0,5, −3/4. Усі обчислення точні, тому відповідь виходить дробом, а десяткове значення додається окремо.

Чи можна розв'язати систему 3×3?

Так, для систем із трьома рівняннями й трьома невідомими. Доступні метод Гауса й метод Крамера, а коефіцієнти можна вводити сіткою.

Що означає «безліч розв'язків»?

Рівняння залежні: одне випливає з іншого. Усі розв'язки задаються формулами через вільну змінну, наприклад x = 2 − y, де y — будь-яке число.

Що означає «розв'язків немає»?

Рівняння суперечать одне одному, наприклад x + y = 2 і x + y = 5. Одночасно вони виконуватись не можуть.

Як перевірити розв'язок системи?

Підставити знайдені значення в кожне рівняння: обидві частини мають збігтися. Калькулятор виконує цю перевірку автоматично й показує підстановку.

Що таке визначник матриці?

Число, обчислене з коефіцієнтів: для 2×2 це ae − bd, для 3×3 — за правилом Саррюса. Якщо воно не дорівнює нулю, система має єдиний розв'язок.

Чим відрізняється система від одного рівняння?

Одне рівняння з двома змінними має безліч розв'язків (пряма), а система двох незалежних рівнянь зазвичай має один: точку перетину двох прямих.
