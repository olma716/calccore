Навіщо потрібна арматура в бетоні

Бетон має чудову міцність на стискання, але дуже слабкий на розтягування та згин. Сталева арматура компенсує цю слабкість — залізобетон (бетон з арматурою) поєднує стискаючу міцність бетону з розтягуючою міцністю сталі, що робить конструкцію значно надійнішою та довговічнішою.

Класи арматурної сталі

Арматура класифікується за класами міцності, які визначають її механічні властивості:

  • А240 (гладка): застосовується переважно для поперечного армування (хомутів), не має ребер, гірше зчеплюється з бетоном.
  • А400 (періодичного профілю): найпоширеніший клас для житлового будівництва — має ребра для кращого зчеплення з бетоном.
  • А500, А600: вища міцність, застосовується у відповідальних конструкціях з підвищеними навантаженнями.

Як розраховується кількість арматури

Арматурна сітка складається з прутків, розміщених у двох перпендикулярних напрямках з певним кроком (відстанню між сусідніми прутками). Кількість прутків у кожному напрямку розраховується як довжина ділянки поділена на крок сітки, плюс один додатковий пруток на край.

Типовий крок сітки залежно від конструкції

  • Стяжка підлоги: 15-20 см, менше навантаження, тонший шар бетону.
  • Фундаментна плита: 20-25 см, залежно від навантаження будівлі та типу ґрунту.
  • Дорожнє покриття: 10-15 см через високі навантаження від транспорту.
  • Монолітні перекриття: зазвичай 15-20 см, з подвійним армуванням (верхній і нижній шар) для роботи на згин в обох напрямках.

Захисний шар бетону над арматурою

Арматура повинна бути повністю занурена в бетон з відступом від поверхні (захисний шар), який захищає сталь від корозії через контакт з вологою та повітрям. Типовий захисний шар становить 20-30 мм для внутрішніх конструкцій та 40-50 мм для фундаментів і зовнішніх елементів, що контактують із ґрунтом чи атмосферними опадами. Для утримання правильного положення арматури використовують спеціальні пластикові чи бетонні фіксатори (стільчики).

Як розрахувати вагу арматури

Знаючи загальну довжину арматури та її діаметр, вагу можна визначити за довідковими таблицями погонної ваги. Орієнтовна вага одного метра: 6мм ≈ 0.222 кг, 8мм ≈ 0.395 кг, 10мм ≈ 0.617 кг, 12мм ≈ 0.888 кг, 14мм ≈ 1.21 кг, 16мм ≈ 1.58 кг. Вага розраховується за формулою: вага = довжина × площа перерізу × густина сталі (7850 кг/м³).

Практичні поради з в'язання арматури

  • В'язальний дріт замість зварювання: для більшості конструкцій арматуру з'єднують в'язальним дротом, а не зварюванням, оскільки зварювання може послабити структуру металу в точці з'єднання.
  • Перепуск (нахлест) прутків: при з'єднанні двох прутків в одну лінію потрібен перепуск довжиною приблизно 30-50 діаметрів прутка для передачі навантаження.
  • Уникай контакту з ґрунтом: арматура ніколи не повинна безпосередньо торкатись землі чи опалубки — завжди використовуй фіксатори для підтримання захисного шару бетону.

Розрахунок є орієнтовним для базового армування. Для відповідальних конструкцій (фундаменти житлових будинків, несучі елементи) обов'язково потрібен проєкт від кваліфікованого інженера-конструктора з урахуванням навантажень та норм безпеки.

Часті запитання

Навіщо потрібна арматурна сітка в бетоні?

Бетон добре витримує стискання, але слабкий на розтягування. Арматура компенсує цю слабкість, суттєво підвищуючи міцність та довговічність конструкції.

Який крок сітки використовують найчастіше?

Для стяжки підлоги типово 15-20 см, для фундаментних плит 20-25 см, залежно від навантаження та товщини конструкції.

Як розрахувати вагу арматури, знаючи лише довжину?

Вага залежить від діаметра прутка — довідкові таблиці вказують вагу одного погонного метра для кожного стандартного діаметра (наприклад, 8мм ≈ 0.395 кг/м, 10мм ≈ 0.617 кг/м).
