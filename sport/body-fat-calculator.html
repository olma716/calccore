Що таке відсоток жиру в тілі

Відсоток жиру в тілі — це частка загальної маси тіла, яка складається з жирової тканини. На відміну від ІМТ, цей показник розрізняє жирову і м'язову масу, тому дає точнішу картину фізичної форми.

Метод ВМФ США (US Navy)

Цей метод оцінює відсоток жиру за обхватами тіла — шиї, талії (і стегон для жінок) — разом зі зростом. Він розроблений для військово-морського флоту США як швидкий і недорогий спосіб оцінки фізичної форми без спеціального обладнання.

Як правильно виміряти обхвати

  • Шия: нижче адамового яблука (кадика), стрічка трохи нахилена вниз спереду.
  • Талія: на рівні пупка, стоячи прямо, після звичайного видиху, без втягування живота.
  • Стегна (для жінок): на рівні найширшої частини сідниць.

Категорії відсотка жиру в тілі

  • Есенційний жир: мінімум, необхідний для життєдіяльності (чоловіки ~2-5%, жінки ~10-13%).
  • Спортивний: характерний для елітних спортсменів (чоловіки 6-13%, жінки 14-20%).
  • Фітнес: добра фізична форма (чоловіки 14-17%, жінки 21-24%).
  • Прийнятний: середній здоровий рівень (чоловіки 18-24%, жінки 25-31%).
  • Ожиріння: підвищений ризик для здоров'я (чоловіки 25%+, жінки 32%+).

Метод обхватів має похибку приблизно ±3-4% порівняно з лабораторними методами (DEXA, гідростатичне зважування). Для точнішої оцінки складу тіла звернись до фахівця з відповідним обладнанням.

Часті запитання

Наскільки точний метод обхватів?

Метод обхватів (US Navy) має похибку приблизно ±3-4% порівняно з лабораторними методами (DEXA-сканування), але є доступним і безкоштовним способом оцінки.

Як правильно виміряти обхват талії?

Виміряй обхват на рівні пупка, стоячи прямо, не втягуючи живіт, після звичайного видиху.

Чому в жінок і чоловіків різні виміри?

Формула для жінок додатково враховує обхват стегон, оскільки розподіл жиру в тілі різниться між статями.

Чи можна довіряти цьому розрахунку на 100%?

Це орієнтовна оцінка. Для точного визначення складу тіла використовуй DEXA-сканування, гідростатичне зважування або біоімпедансометрію у фахівця.
