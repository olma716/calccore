Що вміє графічний калькулятор функцій

Калькулятор будує графік функції y = f(x) і дозволяє досліджувати його: масштабувати, знаходити нулі, екстремуми й точки перетину, будувати таблицю значень, шукати похідну й рівняння дотичної у точці. До шести функцій можна показати на одному полотні, кожна має свій колір, а кружечок біля функції вмикає чи ховає її.

Як вводити функції

Пишіть вираз так, як у зошиті: x^2 − 4x + 3, 2x + 1 (знак множення можна пропускати), 1/x, sqrt(x) або √x, abs(x) чи |x|. Степінь — «^», наприклад x^3 чи 2^x. Підтримуються sin, cos, tg (tan), ctg, asin, acos, atan, sinh, cosh, tanh, ln, lg (log), log2, exp, sqrt, cbrt, abs, sign, floor, ceil, а також числа π (pi) та e. Вертикальну пряму задайте як x = 3. У налаштуваннях можна обрати градуси замість радіанів.

Нулі, екстремуми й перетини

Нулі — точки, де f(x) = 0, тобто перетини з віссю x. Екстремуми — локальні максимуми й мінімуми, де похідна змінює знак. Для x² − 4x + 3 нулі 1 і 3, а вершина (2; −1) — мінімум. Точки перетину двох графіків — розв'язки f₁(x) = f₂(x): для x² − 4x + 3 і x − 1 це x = 1 та x = 4. Калькулятор знаходить їх числово й підказує точний вигляд: дріб, кратне π чи √n.

Таблиця значень

У вкладці «Таблиця значень» вкажіть x від, до та крок, і всі видимі функції відобразяться стовпчиками. Для поліномів і дробів при раціональному x значення точні (наприклад, 1/3), для решти функцій — з обраною кількістю знаків. Таблицю можна скопіювати.

Похідна й дотична

Похідна знаходиться символьно за правилами диференціювання: (x³ − 3x)' = 3x² − 3. Дотична до графіка в точці x₀: y = f(x₀) + f'(x₀)(x − x₀). Для f(x) = x³ − 3x і x₀ = 2 маємо f(2) = 2, f'(2) = 9, тож дотична y = 9x − 16. Нормаль — пряма, перпендикулярна до дотичної в цій самій точці, її кутовий коефіцієнт −1/f'(x₀).

Типові графіки

Лінійна y = kx + b — пряма, k — нахил. Квадратична y = ax² + bx + c — парабола, вершина в x = −b/(2a). Гіпербола y = 1/x має асимптоти x = 0 та y = 0. Корінь y = √x визначений при x ≥ 0, логарифм y = ln x — при x > 0. Синус і косинус періодичні з періодом 2π, тангенс має вертикальні асимптоти в точках π/2 + πn. Експонента y = eˣ зростає, не перетинаючи вісь x.

Усі обчислення виконуються в браузері. Вираз розбирається власним парсером, без передачі даних на сервер.

Часті запитання

Як побудувати графік функції онлайн?

Введіть вираз у поле f₁(x), наприклад x^2 − 4x + 3, і графік з'явиться одразу. Щоб додати ще одну функцію, натисніть «Додати функцію».

Як знайти нулі функції?

Перейдіть у вкладку «Аналіз функції» або залиште позначку «Характерні точки»: нулі показані зеленими точками. Для x² − 4x + 3 це 1 і 3.

Як знайти точку перетину двох графіків?

Введіть обидві функції: точки перетину позначаються фіолетовим і перелічені під графіком. Для x² − 4x + 3 і x − 1 це x = 1 та x = 4.

Як знайти екстремум функції?

Екстремум — точка, де похідна змінює знак. Калькулятор знаходить мінімуми й максимуми та показує їх на графіку й у вкладці «Аналіз».

Як знайти дотичну до графіка?

У вкладці «Дотична» оберіть функцію й точку x₀. Рівняння: y = f(x₀) + f'(x₀)(x − x₀). Для x³ − 3x при x₀ = 2 це y = 9x − 16.

Як записати функцію з коренем, модулем чи степенем?

sqrt(x) або √x, abs(x) або |x|, x^3, 2^x. Знак множення можна пропускати: 2x, 3(x + 1).

Чи можна користуватися градусами?

Так: у налаштуваннях оберіть «Градуси», і sin(30) дорівнюватиме 0,5. За замовчуванням кути в радіанах.

Як змінити масштаб графіка?

Колесом миші, щипком двома пальцями, подвійним натисканням або кнопками «+» і «−». Також можна вписати межі x та y вручну.

Як побудувати вертикальну пряму?

Введіть x = 3 (число, а не вираз із x): буде вертикальна пряма в цій точці.

Чому функція не показується в деяких точках?

У цих точках вона не визначена: наприклад, 1/x при x = 0, ln x при x ≤ 0, √x при x < 0. На графіку там розрив.

Як зберегти графік?

Кнопка «Зберегти PNG» завантажує малюнок. Кнопка «Поділитись» копіює посилання, що відновлює функції й масштаб.

Чи надсилаються мої дані кудись?

Ні. Усі обчислення виконуються у вашому браузері.
