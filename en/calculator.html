How to use the scientific calculator

This calculator combines basic arithmetic (+, −, ×, ÷) with scientific functions: trigonometry (sin, cos, tan), logarithms (log, ln), powers, roots, factorial, plus memory and calculation history.

Key features

  • Trigonometry — sin, cos, tan and inverse functions (via the "Inv" button), degrees/radians toggle.
  • Powers and roots — x², xʸ, √, 1/x.
  • Logarithms — log (base 10) and ln (natural).
  • Factorial — n! for non-negative integers.
  • Memory — MC, MR, M+, M−, MS to store intermediate results.
  • History — all previous calculations; click an entry to reuse the result.

Keyboard input is supported: digits, +, −, *, /, parentheses, Enter (=), Backspace, Escape (reset).

FAQ

How do I switch between degrees and radians?

Use the DEG/RAD toggle above the display. It affects sin, cos, tan and their inverse functions.

What does the "Inv" button do?

It switches sin/cos/tan to their inverse functions — arcsin, arccos, arctan.

How does memory work?

MS stores the current result, MR recalls it, M+/M− add or subtract from memory, MC clears it.

Can I use the keyboard?

Yes — digits, basic operators, parentheses, Enter for "=", Backspace to delete, Escape to fully reset.
