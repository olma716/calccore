Що вміє калькулятор теореми Піфагора

Калькулятор розв'язує п'ять типових задач: знаходить гіпотенузу або катет за двома відомими сторонами, перевіряє за оберненою теоремою, чи прямокутний трикутник із заданими сторонами, рахує діагональ прямокутної коробки, відстань між двома точками на площині й у просторі та підбирає піфагорові трійки. Відповідь записується точно, з радикалами, наприклад 5√2, а поруч стоїть десяткове наближення. До кожного результату додаються периметр, площа, кути й схема.

Формула теореми Піфагора

У прямокутному трикутнику квадрат гіпотенузи дорівнює сумі квадратів катетів: a² + b² = c². Тут a і b — катети (сторони при прямому куті), c — гіпотенуза (найдовша сторона, що лежить навпроти прямого кута). Теорема працює лише для прямокутних трикутників.

Як знайти гіпотенузу

Якщо відомі обидва катети, гіпотенуза c = √(a² + b²). Для катетів 3 і 4 маємо c = √(9 + 16) = √25 = 5. Для катетів 1 і 1 маємо c = √2 ≈ 1,4142: калькулятор покаже і точний запис, і наближення. Та сама формула дає діагональ прямокутника зі сторонами a і b.

Як знайти катет

Якщо відомі гіпотенуза й один катет, інший знаходять за формулою a = √(c² − b²) (або b = √(c² − a²)). Для c = 13 і a = 5 маємо b = √(169 − 25) = √144 = 12. Гіпотенуза завжди довша за будь-який катет, тому при c ≤ b чи c ≤ a задача розв'язків не має, і калькулятор про це повідомить.

Чи прямокутний трикутник: обернена теорема

Якщо в трикутнику квадрат найбільшої сторони дорівнює сумі квадратів двох інших, трикутник прямокутний. Для сторін 7, 24, 25: 49 + 576 = 625 = 25², тож трикутник прямокутний. Якщо сума квадратів більша, трикутник гострокутний (для 4, 5, 6: 16 + 25 = 41 > 36), якщо менша — тупокутний (для 2, 3, 4: 4 + 9 = 13 < 16). Калькулятор порівнює точно, тому не помиляється навіть на десяткових сторонах, а ще перевіряє нерівність трикутника й показує найбільший кут.

Піфагорові трійки

Піфагорова трійка — це три натуральні числа a, b, c, для яких a² + b² = c². Найвідоміші: (3, 4, 5), (5, 12, 13), (8, 15, 17), (7, 24, 25), (20, 21, 29), (9, 40, 41). Усі примітивні трійки (без спільного дільника) дає формула Евкліда: a = m² − n², b = 2mn, c = m² + n², де m > n, числа m і n взаємно прості й різної парності. Наприклад, m = 2, n = 1 дає (3, 4, 5), m = 3, n = 2 дає (5, 12, 13), m = 4, n = 3 дає (7, 24, 25). Усі інші трійки — це примітивні, помножені на k = 2, 3, … Із гіпотенузою до 100 існує 52 трійок, із них 16 примітивних. Із числом 12 є 4 трійки: (5, 12, 13), (9, 12, 15), (12, 16, 20), (12, 35, 37).

Діагональ коробки й відстань між точками

Діагональ прямокутної коробки з ребрами a, b, c дорівнює d = √(a² + b² + c²): теорему Піфагора застосовують двічі, спершу до діагоналі основи, потім до трикутника з висотою c. Для 3 × 4 × 12 діагональ основи 5, а діагональ коробки √(25 + 144) = 13. Відстань між точками (x₁; y₁) і (x₂; y₂) дорівнює d = √((x₂ − x₁)² + (y₂ − y₁)²), у просторі додається доданок (z₂ − z₁)². Для (1; 2) і (4; 6) маємо √(9 + 16) = 5.

Де застосовують теорему Піфагора

У будівництві й столярній справі прямий кут розмічають за «єгипетським трикутником» зі сторонами 3, 4, 5 (чи 6, 8, 10): якщо діагональ дорівнює 5, кут прямий. Драбина довжиною 5 м, поставлена на відстані 3 м від стіни, сягає висоти 4 м. Діагональ екрана 40 × 30 см дорівнює 50 см. Відстань між точками на карті, довжина діагоналі кімнати чи шафи, крок схилу, висота опори — усе це задачі на теорему Піфагора.

Усі введені числа обробляються точно (дроби не округлюються), а корені спрощуються: наприклад, √50 записується як 5√2.

Часті запитання

Що таке теорема Піфагора?

У прямокутному трикутнику квадрат гіпотенузи дорівнює сумі квадратів катетів: a² + b² = c².

Як знайти гіпотенузу?

За формулою c = √(a² + b²). Для катетів 3 і 4 гіпотенуза 5.

Як знайти катет?

За формулою a = √(c² − b²) або b = √(c² − a²). Для c = 13 і a = 5 катет b = 12.

Для яких трикутників працює теорема Піфагора?

Тільки для прямокутних. Для довільного трикутника діє теорема косинусів: c² = a² + b² − 2ab·cos γ, а для γ = 90° вона перетворюється на теорему Піфагора.

Що буде, якщо гіпотенуза менша за катет?

Такі дані неможливі: гіпотенуза завжди найдовша сторона прямокутного трикутника. Калькулятор покаже повідомлення про помилку.

Як перевірити, що трикутник прямокутний?

Знайдіть найбільшу сторону й порівняйте її квадрат із сумою квадратів двох інших. Рівність означає прямий кут (обернена теорема Піфагора). Для 7, 24, 25: 49 + 576 = 625.

Що таке піфагорова трійка?

Три натуральні числа a, b, c, для яких a² + b² = c², наприклад (3, 4, 5) чи (5, 12, 13). Примітивні трійки не мають спільного дільника, а решта виходить множенням на k.

Як знайти діагональ прямокутника чи коробки?

Діагональ прямокутника a × b дорівнює √(a² + b²). Діагональ коробки a × b × c дорівнює √(a² + b² + c²). Для 3 × 4 × 12 вона дорівнює 13.

Як знайти відстань між двома точками?

d = √((x₂ − x₁)² + (y₂ − y₁)²), а у просторі ще додається (z₂ − z₁)². Для (1; 2) і (4; 6) відстань 5.

Скільки існує піфагорових трійок?

Нескінченно багато. Із гіпотенузою до 100 їх 52, з яких 16 примітивних. Калькулятор покаже список для будь-якого N до 10 000.

Чи можна вводити дроби й десяткові числа?

Так: 2,5 або 5/2. Числа обробляються точно без округлень, тому відповідь може мати вигляд кореня, наприклад 5√2.

Чому відповідь записана з коренем?

Бо квадрат шуканої сторони — раціональне число, а корінь із нього спрощується точно: √50 = 5√2. Поруч завжди є десяткове значення, а його точність задають знаки після коми.
