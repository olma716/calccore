What the generator does

The generator creates QR codes for text and links, a Wi-Fi network, a contact card, an email, an SMS, a call and a location. Enter the data on the matching tab and the code updates at once. Cyrillic and emoji are supported. The finished code can be downloaded as PNG or SVG or copied as an image, and the encoded text can be copied separately.

Wi-Fi without typing the password

On the Wi-Fi tab enter the network name, the security type and the password: a guest points the camera and connects without typing. Special characters in the name and password (semicolon, colon, comma, quotes, backslash) are escaped automatically by the format WIFI:T:…;S:…;P:…;;. The password is built into the code itself, so do not post such a code where outsiders should not see it.

A contact card and messages

The “Contact” tab builds a contact in the vCard 3.0 format: name, company, job title, phone, email, website, address and a note. A phone reads the code and offers to add the contact to the address book. The “Email, SMS, phone” tab creates a ready email with a subject and text, an SMS, a call to a number or a map point by latitude and longitude.

Encoding modes and correction levels

The generator picks the densest mode on its own: digits, capital letters with digits and a few symbols, or UTF-8 bytes. The error correction level L, M, Q or H restores about 7, 15, 25 and 30% of damage respectively. The default is “Auto”: it takes the highest level that does not make the code bigger, so the code is sturdier for free.

Size, version and capacity

A QR code has versions from 1 to 40, from 21×21 to 177×177 modules. The biggest version holds up to 7089 digits, 4296 letters with digits or 2953 bytes. Cyrillic and emoji take 2–4 bytes per character, so a long text quickly makes the code bigger. The less data, the more reliably the code scans from a distance, so for links a short address is better.

Colours, quiet zone and printing

Dark modules on a light background scan most reliably. The generator checks the contrast and warns about an inverted code (light modules on a dark background), a transparent background and a small quiet zone: the standard advises at least 4 modules. For PNG the scale is a whole number so the edges stay sharp, while the SVG scales without loss and suits printing. Scan the code with several phones before a print run.

Limits

The generator creates static codes: they do not track visits and do not expire, but the content cannot be changed after printing. Bank payment QR codes have their own formats and are not supported here. How well the SMS and Wi-Fi formats work depends on the app that scans the code, so test the code on your own phone.

Always scan the code with several phones before printing. Dark modules on a light background, a quiet zone of at least 4 modules and a short link make the code reliable even in small print.

FAQ

Is it safe to create a QR code on a website?

Here it is: the code is created in your browser, the data is not sent to a server or put in the link, browser storage or analytics, and no link to the result is created.

Does a code with Cyrillic and emoji work?

Yes, the text is encoded in UTF-8. Modern phones read such codes correctly, but each character takes 2–4 bytes, so the code is bigger.

Does such a QR code expire?

No, it is a static code: the data is written in the image itself. If the link you encoded later changes or disappears, the code leads to the old address.

What is the error correction level?

It is a reserve that lets the code be read despite scratches or a logo: L restores about 7% of the data, M 15%, Q 25% and H 30%. A higher level makes the code bigger.

Which level should I choose?

Leave “Auto”: it takes the highest level that does not make the code bigger. For small or worn surfaces choose H, and for long data L.

How do I make a QR code for Wi-Fi?

Open the Wi-Fi tab, enter the network name and password, choose the security type and mark a hidden network if needed. A guest points the camera and connects.

Why does a phone not open the code as a link?

Most likely the address was entered without https://. Add the protocol and the phone opens it as a link rather than plain text.

Why does the code not scan?

Check the contrast, a quiet zone of at least 4 modules, the size and the amount of data. Inverted and very colourful codes scan worse. Shorten the text or the link.

Which format should I download: PNG or SVG?

PNG suits documents, email and websites. SVG is a vector, scales without loss and suits large print runs better.

How much data does a QR code hold?

The biggest code holds up to 7089 digits, 4296 letters with digits or 2953 bytes, depending on the correction level. The generator tells you when there is too much data.

Can I put a logo in the centre?

No, this generator has no logo in the centre. A logo covers modules, so it needs a higher correction level and must be tested with a scanner.

Can I create a QR code for a payment?

No, bank payment codes have their own formats. The generator creates codes for text, links, Wi-Fi, contacts, emails, SMS, calls and locations.
