What the system of equations calculator does

The calculator solves systems of linear equations with two or three unknowns. For a 2×2 system you can pick substitution, elimination (addition) or Cramer's rule; for 3×3 — Gauss' method or Cramer's rule. Type the equations as on paper (with brackets, fractions and variables on both sides of “=”) or enter the coefficients. Every system comes with a step-by-step solution and a check by substitution, and a 2×2 system also gets a graph of two lines where the solution is their intersection.

Substitution

Express one variable from one equation, substitute it into the other and get an equation in one variable. After finding it, go back to the expression and compute the second variable. For x + y = 5, 2x − y = 1 we get y = 5 − x, then 2x − (5 − x) = 1, 3x − 5 = 1, x = 2 and y = 5 − 2 = 3.

Elimination (addition)

Multiply the equations by numbers that make the coefficients of one variable equal in absolute value, then add or subtract the equations so that this variable cancels. For the same system the coefficients of y are already opposite (+1 and −1): adding the equations gives 3x = 6, x = 2, and from the first equation y = 5 − 2 = 3.

Cramer's rule (determinants)

For the system ax + by = c, dx + ey = f the determinants are D = ae − bd, Dx = ce − bf, Dy = af − cd, and the solution is x = Dx / D, y = Dy / D (if D ≠ 0). For x + y = 5, 2x − y = 1 we have D = -3, Dx = -6, Dy = -9, so x = 2 and y = 3. For 3×3 systems the determinants are computed by Sarrus' rule: D = 7, Dx = 7, Dy = 14, Dz = 21 for x + y + z = 6, 2x − y + z = 3, x + 2y − z = 2, hence x = 1, y = 2, z = 3.

Gauss' method

Write the system as an augmented matrix and use row operations (swapping rows, dividing a row by a number, subtracting a multiple of a row) to bring it to a form where the solution is visible at once. The calculator shows the matrix after every step. The method also works when the determinant is zero and gives the rank of the matrix.

Infinitely many solutions and no solution

If the equations of a system are dependent, for example x + y = 2 and 2x + 2y = 4, there are infinitely many solutions: the lines coincide, and the calculator writes the general solution (for example x = 2 − y where y is any number). If the equations contradict each other, like x + y = 2 and x + y = 5, there is no solution: the lines are parallel and the reduction produces a row 0 = c with c ≠ 0.

All calculations are exact: the coefficients are kept as rational numbers, so the solution comes out as a fraction without rounding.

FAQ

What is a system of linear equations?

A set of several linear equations with the same unknowns that must be solved at once: find the values of the variables that satisfy all the equations.

Which method should I choose for a 2×2 system?

Substitution is handy when some equation has a coefficient 1 at a variable. Elimination is faster when the coefficients are easy to match. Cramer's rule is good for a formula-based solution and when you need the determinant.

When does Cramer's rule not work?

When the main determinant D = 0: the system has either no solution or infinitely many. The calculator then decides which one by reducing the matrix with Gauss' method.

How many solutions can a system have?

One (the lines intersect), none (the lines are parallel) or infinitely many (the lines coincide). For 3×3 these are the corresponding positions of three planes.

How do I enter a system with variables on both sides?

Just type the equations as they are, for example 2x + 3 = y - 1 and x - y = 4. The calculator moves the variables to the left and the numbers to the right and shows this step.

Can I use fractions and decimals?

Yes: 1/2, 0.5, −3/4. All calculations are exact, so the answer is a fraction and the decimal value is added separately.

Can I solve a 3×3 system?

Yes, for systems of three equations in three unknowns. Gauss' method and Cramer's rule are available, and the coefficients can be entered in a grid.

What does “infinitely many solutions” mean?

The equations are dependent: one follows from the other. All solutions are given by formulas through a free variable, for example x = 2 − y where y is any number.

What does “no solutions” mean?

The equations contradict each other, for example x + y = 2 and x + y = 5. They cannot hold at the same time.

How do I check a solution of a system?

Substitute the values into each equation: both sides must match. The calculator does this check automatically and shows the substitution.

What is the determinant of a matrix?

A number computed from the coefficients: for 2×2 it is ae − bd, for 3×3 it follows Sarrus' rule. If it is not zero, the system has a unique solution.

How is a system different from a single equation?

One equation in two variables has infinitely many solutions (a line), while a system of two independent equations usually has one: the intersection of two lines.
