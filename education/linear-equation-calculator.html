Що вміє калькулятор лінійного рівняння

Калькулятор розв'язує лінійні рівняння з однією змінною і працює в чотирьох режимах: рівняння (його вводять так, як записано на папері: з дужками, дробами й змінною з обох боків), рівняння за коефіцієнтами ax + b = cx + d, лінійні нерівності з числовою прямою та пропорції A : B = C : D. Для кожного прикладу показано розв'язання по кроках, перевірку підстановкою й, для рівнянь, графік двох прямих, де розв'язок є точкою їхнього перетину.

Як розв'язати лінійне рівняння

Лінійне рівняння має вигляд ax + b = 0, або, загальніше, ax + b = cx + d. Щоб його розв'язати, розкривають дужки, переносять доданки зі змінною в один бік, а числа в інший (знак при перенесенні змінюється на протилежний), зводять подібні доданки й ділять обидві частини на коефіцієнт при x.

Приклад: 3x − 7 = 2x + 5. Переносимо: 3x − 2x = 5 + 7, тобто x = 12. Перевірка: 3·12 − 7 = 29 і 2·12 + 5 = 29. Приклад із дужками: 2(x + 3) = 14, тобто 2x + 6 = 14, 2x = 8, x = 4. Якщо в рівнянні є дроби, як у (x + 1)/2 = x/3 + 4, обидві частини множать на найменше спільне кратне знаменників, тут це 6: 3(x + 1) = 2x + 24, 3x + 3 = 2x + 24, звідки x = 21.

Безліч розв'язків і випадок без розв'язків

Якщо після перенесення коефіцієнт при x дорівнює нулю, змінна зникає. Рівняння 2x + 1 = 2x + 5 приводить до рівності 1 = 5, яка неможлива, тому розв'язків немає: на графіку прямі паралельні. Рівняння 2(x + 1) = 2x + 2 приводить до 0 = 0, яка правильна за будь-якого x, тому розв'язків безліч: прямі збігаються.

Лінійні нерівності

Нерівності розв'язують так само, як рівняння, але з одним правилом: коли обидві частини діляться на від'ємне число, знак нерівності змінюється на протилежний. Наприклад, −2x + 3 > 7 дає −2x > 4, а після ділення на −2 маємо x < −2, тобто проміжок (−∞; −2). Для нестрогих знаків ≤ і ≥ межа входить у відповідь, на числовій прямій вона позначається закрашеною точкою.

Пропорції

Пропорція A : B = C : D виконується, коли добуток крайніх членів дорівнює добутку середніх: A·D = B·C. Невідомий член знаходять діленням. Для 3 : 4 = 9 : x маємо 3·x = 4·9, звідки x = 36 / 3 = 12.

Усі обчислення точні: коефіцієнти зберігаються як раціональні числа, тому 1/3 не перетворюється на 0,333 під час розв'язання.

Часті запитання

Що таке лінійне рівняння?

Рівняння першого степеня з однією змінною, яке зводиться до виду ax + b = 0, де a і b — числа. Наприклад, 3x − 7 = 2x + 5 — лінійне рівняння.

Як знайти x у рівнянні ax + b = 0?

Перенести b у праву частину: ax = −b, а потім поділити обидві частини на a: x = −b/a. Для 2x − 8 = 0 маємо x = 8/2 = 4.

Як розв'язати рівняння з дужками?

Спочатку розкрити дужки, потім звести подібні доданки. Для 2(x + 3) = 14 маємо 2x + 6 = 14, 2x = 8, x = 4.

Як розв'язати рівняння з дробами?

Помножити обидві частини на найменше спільне кратне знаменників. Для (x + 1)/2 = x/3 + 4 це 6: 3(x + 1) = 2x + 24, тому x = 21. Калькулятор показує цей крок і рахує дроби точно.

Коли лінійне рівняння не має розв'язків?

Коли після спрощення змінна зникає, а рівність неправильна. Наприклад, 2x + 1 = 2x + 5 дає 1 = 5, тому розв'язків немає.

Коли розв'язків безліч?

Коли змінна зникає, а рівність правильна за будь-якого x. Наприклад, 2(x + 1) = 2x + 2 дає 0 = 0: розв'язком є будь-яке число.

Чи можна вводити дроби й десяткові числа?

Так: 1/2, 0,5, −3/4. Калькулятор рахує точно на раціональних числах, тому відповідь виходить дробом, а десяткове значення додається окремо.

Чи можна використовувати іншу змінну, не x?

Так, допускається одна змінна-літера, наприклад y або t. Якщо в рівнянні дві різні літери, калькулятор це підкаже.

Що робити, якщо в рівнянні є x²?

Якщо x² не скорочується (як у x² + x = x² + 3), це вже квадратне рівняння. Калькулятор підкаже перейти на калькулятор квадратного рівняння.

Чому при діленні на від'ємне число знак нерівності змінюється?

Бо множення чи ділення на від'ємне число змінює порядок чисел на числовій прямій: з 2 < 3 після множення на −1 виходить −2 > −3. Тому −2x > 4 дає x < −2.

Що таке пропорція й основна властивість пропорції?

Пропорція — рівність двох відношень, A : B = C : D. Основна властивість: добуток крайніх членів дорівнює добутку середніх, A·D = B·C.

Як перевірити відповідь?

Підставити знайдене x в обидві частини вихідного рівняння: якщо числа збігаються, відповідь правильна. Калькулятор виконує цю перевірку автоматично й показує підстановку.
