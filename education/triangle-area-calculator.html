Що вміє калькулятор площі трикутника

Калькулятор знаходить площу трикутника п'ятьма способами: за основою й висотою, за трьома сторонами (формула Герона), за двома сторонами й кутом між ними, за координатами вершин і для особливих видів (рівносторонній, рівнобедрений, прямокутний). Відповідь записується точно, з радикалами, наприклад 6√6, і поруч стоїть десяткове наближення. За трьома сторонами додатково знаходяться периметр, висоти, кути, радіуси вписаного й описаного кіл та вид трикутника.

Площа за основою й висотою

S = a · h / 2, де a — основа, h — висота, проведена до неї. Для a = 6 і h = 4 маємо S = 6 · 4 / 2 = 12. Висота може лежати поза трикутником (у тупокутного), але формула та сама.

Формула Герона

Якщо відомі три сторони a, b, c, спершу знаходять півпериметр p = (a + b + c) / 2, а потім S = √(p(p − a)(p − b)(p − c)). Для 3, 4, 5 маємо p = 6 і S = √(6 · 3 · 2 · 1) = 6. Для 5, 6, 7 маємо p = 9 і S = √(9 · 4 · 3 · 2) = √216 = 6√6 ≈ 14,6969. Калькулятор рахує під коренем точно, тому відповідь не втрачає точності навіть для дуже витягнутих трикутників.

Дві сторони й кут між ними

S = a · b · sin γ / 2. Для a = 8, b = 5 і γ = 30° маємо sin 30° = 1/2, тому S = 8 · 5 · (1/2) / 2 = 10. Для кутів 30°, 45°, 60°, 90°, 120°, 135° і 150° синус відомий точно, і відповідь виходить з радикалом (наприклад, для 60° це ab√3/4), а для інших кутів — наближено.

Площа за координатами вершин

Для вершин A(x₁; y₁), B(x₂; y₂), C(x₃; y₃) площа дорівнює S = |x₁(y₂ − y₃) + x₂(y₃ − y₁) + x₃(y₁ − y₂)| / 2. Для A(0; 0), B(4; 0), C(0; 3) маємо |0 + 4 · 3 + 0| / 2 = 6. Якщо вираз під модулем дорівнює нулю, точки лежать на одній прямій і трикутника немає.

Рівносторонній, рівнобедрений і прямокутний трикутники

У рівносторонньому трикутника зі стороною a площа S = a²√3 / 4: для a = 6 це 9√3 ≈ 15,5885. У рівнобедреному з основою b і бічною стороною a висота h = √(a² − b²/4), а S = b · h / 2: для b = 6 і a = 5 висота 4, площа 12. У прямокутному з катетами a і b площа S = ab / 2, а гіпотенуза c = √(a² + b²): для 3 і 4 площа 6, c = 5.

Висоти, кути й радіуси кіл

Висота до сторони a дорівнює 2S / a. Кути знаходять за теоремою косинусів: cos A = (b² + c² − a²) / (2bc); для 5, 6, 7 кут A ≈ 44,4153°. Радіус вписаного кола r = S / p, описаного R = abc / (4S): для 5, 6, 7 це ≈ 1,633 і ≈ 3,5722. Вид трикутника за кутами визначається порівнянням квадрата найбільшої сторони з сумою квадратів двох інших.

Усі введені числа обробляються точно (дроби не округлюються), а корені спрощуються: наприклад, площа 5, 6, 7 записується як 6√6.

Часті запитання

Як знайти площу трикутника?

Найпростіше S = a · h / 2: половина добутку основи на висоту. Якщо висоти немає, використовують формулу Герона, добуток двох сторін на синус кута або координати вершин.

Як знайти площу за трьома сторонами?

За формулою Герона: p = (a + b + c) / 2, S = √(p(p − a)(p − b)(p − c)). Для сторін 3, 4, 5 площа 6.

Як знайти площу за двома сторонами й кутом?

S = a · b · sin γ / 2, де γ — кут між цими сторонами. Для 8, 5 і 30° площа 10.

Як знайти площу за координатами?

S = |x₁(y₂ − y₃) + x₂(y₃ − y₁) + x₃(y₁ − y₂)| / 2. Для A(0; 0), B(4; 0), C(0; 3) площа 6.

Як знайти площу рівностороннього трикутника?

S = a²√3 / 4. Для a = 6 це 9√3 ≈ 15,5885.

Як знайти площу прямокутного трикутника?

Половина добутку катетів: S = ab / 2. Для катетів 3 і 4 це 6, а гіпотенуза 5.

Як знайти площу рівнобедреного трикутника?

Спершу висота до основи h = √(a² − b²/4), потім S = b · h / 2. Для b = 6 і a = 5 площа 12.

Коли трикутник існує?

Коли кожна сторона менша за суму двох інших (нерівність трикутника). Якщо одна сторона дорівнює сумі двох інших, трикутник вироджується у відрізок.

Як визначити вид трикутника?

За сторонами: рівносторонній, рівнобедрений, різносторонній. За кутами: порівняти квадрат найбільшої сторони з сумою квадратів двох інших: рівність — прямокутний, менше — гострокутний, більше — тупокутний.

Що таке радіуси вписаного й описаного кіл?

r = S / p — радіус кола, вписаного в трикутник, R = abc / (4S) — радіус кола, описаного навколо нього. Калькулятор показує їх для трьох сторін.

Чи можна вводити дроби й десяткові числа?

Так: 2,5, 5/2, −1/3 для координат. Числа обробляються точно без округлень, тому відповідь може мати вигляд кореня.

Чому відповідь записана з коренем?

Бо квадрат площі — раціональне число, а корінь із нього спрощується точно: √216 = 6√6. Поруч завжди є десяткове значення, і його точність задають знаки після коми.
